Безпека сервісних API

Keycloak · OAuth 2.0 Authorization Code · PKCE S256 · окремі scopes

1. Увійти

Виберіть запитувані права. Сервер видає лише scopes, дозволені ролями користувача.

Немає активного access token

Локально: user5 / User5-demo! — усі права; reader5 / Reader5-demo! — лише читання. Зовнішній для realm провайдер: upstream5 / Upstream5-demo! — читання.

2. Перевірити ресурси

Відповіді API з’являться тут.
Токен зберігається лише в пам’яті вкладки. Після оновлення сторінки увійдіть знову. Копіюйте токен лише для локальних перевірок.
